# Powerful6700 · Windows 0.3.0-win.1

Sony A6700 工具 [Powerful6700](https://github.com/xyzhangxin/sony-a6700-powerful)（上游 0.2.0，GPL-3.0）的 Windows 端实现。

## 本版新增：自定义外观

- 菜单第 2 项 → **Classic Chrome**，第 3 项 → **Classic Negative**（逐色相 RMS 0.194 / 0.190，按 A7C2 的 19 张直出对照图定标）；
- 第 4 项 → **Positive Film**、第 5 项 → **Negative Film**（低饱和轻量版）；
- 新增 `tools/looks_apply.py` + `docs/looks-profile.json`：一条命令幂等写入四个外观；
- 新增 `docs/LOOKS.md`（能力、边界、还原步骤）与 `docs/LOOK-COLOR.md`（全部调查数据与失败路径）。

### 本版修复

- **界面重排版**：内容列固定 800px 居中、页脚与内容列对齐、卡片说明改到标题下方、「操作前须知」的 5 条改成 01–05 编号段落流；按钮一律右对齐、从左到右就是操作顺序。排版规则与新截图见 \`docs/UI.md\` 与 \`docs/images/ui/\`。

- **界面改成分步引导**：左侧导航即操作顺序，每页顶部标「第 N 步 · 共 6 步」，底部「← 上一步 / 下一步」带门闸，缺什么直接写在按钮旁边；
- **修掉「兼容性检查未通过 / blocked」误报**：/usr 分区里有 9 个结构守卫扇区落在 ext2 inode 表上，相机自己会刷新 inode 时间戳，导致什么都没做也判不兼容。现在只对这 9 个扇区的 atime/ctime/mtime（每个 inode 12 字节）放行，内容与其余字节仍逐字节校验。

边界：只能改颜色倾向，做不出富士的 S 形影调；`.cube` / `.dcp` 不能直接导入。

## 适用范围

- 仅 **Sony A6700（ILCE-6700），固件 2.00**
- Windows 10 / 11 x64
- 首次把相机 USB 接口绑定到 WinUSB 需要管理员权限

## 实机验证过的路径（本机 A6700 + 2.00）

| 路径 | 结果 |
| --- | --- |
| 只读检查 | 260 扇区 / 133,120 字节，兼容性通过，六项功能状态读出 |
| 功能状态备份 | 41,582 字节 `.a6700backup`，SHA-256 复算一致 |
| 解锁写入 | `completed`，相机内二次校验 + 独立回读通过 |
| 关闭写入 | `completed`，`touched=4`，重启后仍为关闭 |
| 备份恢复 | `restored`，134 扇区 / 326 字节回写 + 独立回读 |

**未验证**：失败回滚（需人为制造相机内校验失败）、跨固件/跨机型、干净机器上的驱动引导全流程。

## 安装与运行

1. 解压 `Powerful6700-Windows-x64.zip`，得到 `Powerful6700\` 目录（绿色版，无需安装）
2. 相机设为 **USB 连接模式 = 海量存储(MSC)**，关闭 FTP，接一根数据线且只接一台目标相机
3. 双击 `Powerful6700.exe`（首次绑定驱动建议右键「以管理员身份运行」）
4. 「操作前须知」：启动检查 → 勾选阅读确认 → 底部「下一步：驱动准备」
5. 「驱动准备」页：扫描设备 → 下载驱动组件 → 绑定 WinUSB（0x0E76；第一次只读检查时出现的 0x0336 会由程序自动绑定）
6. 「相机准备」四项确认 → 开始只读检查 → 「功能管理」勾选功能 → 解锁／关闭
