# Powerful6700 · Windows 端开发进展（2026-10-25）

Sony A6700（固件 2.00）工具的 Windows 版，对标 A7C2 那套项目的完成度。

**💥 新增功能：**

1. 菜单文字改写与还原，已完整实现——PT / NT / VV / VV2 四个槽位在相机菜单里可以显示
   `Classic Chrome` / `Classic Neg.` / `Positive Film` / `Negative Film`，也可以显示
   `富士CC` / `富士NC` / `理光正片` / `理光负片`，两套命名界面里一键切换；写完能逐字节还原回出厂
   （145,708 ↔ 145,612 字节，回读 SHA-256 一致）
2. 只读检查的报错说清楚了——相机拒绝时直接写明卡在 `配置写入（SET_FILE2）` 还是 `载荷写入（SET_FILE）`，
   附状态字含义与恢复步骤（拔线 → 关机 → 取电池 1 分钟 → 装回 → 重连 MSC）
3. 驱动准备全自动——SetupAPI 扫描相机接口、下载 libwdi 组件、提权把接口绑到 WinUSB；
   真机已验证相机从 `0x0E76` 绑到 `winusb`
4. 服务模式自救——认证后相机卡在 `0x0336` 时，自动发 STOP_SENSER 把它送回海量存储模式
5. 写入载荷扩到 `/setting/`（为整单元写回 `BACKUP.BIN` 留通路，尚未真机验证）
6. 交接文档与标定文档入仓——`docs/AI-HANDOFF.md`、`docs/CALIBRATION.md`

**🧑‍💻 旧功能优化：**

1. 自定义外观（富士 / 理光滤镜）
   - 修掉了蓝端溢出：色度记录里的 v6 是白点配平项，改成等比缩放后蓝端不再炸
   - 以 A7C2 直出 19 张对照图（72 个样本）为参照，做 12 档色相色度拟合，当前矫正率
     **81.7% / 82.7% / 81.1% / 67.0%**（CC / NC / PF / NF）
   - CC 还在调：离线试到 RMS 0.194 → **0.164**（矫正率 80.6% → 83.6%），待实拍观感验收
2. 写 145 KB 语言资源会越界失败——改成先 `truncate` 再分块写，第 5 块不再报状态 12
3. 掉线恢复——块级修复只重写差异块，传输量减半
4. 蓝端定位——色度层对蓝端不敏感，真正的旋钮在矩阵单元 `0x02A4000D` 的 block 4（单向，
   整块填 20000 时蓝 0–30° 档 6.2 倍），块内二分尚未做

**❌ 可行性验证不通过：**

1. 官方 3D LUT 直接套用——富士官方 19 个 LUT 全是 `F-Log / F-Gamut → ETERNA / WDR` 的录制域转换，
   A6700 只有 S-Log3 / HLG，输入域接不上
2. Resolve 导出的 `.cube` 当基准——灰阶被烤成 S 曲线（0.25→0.083、0.5→0.690），四种域解释与相机 CC
   差 RMS 0.53–1.19，不能当「CC 应该是什么颜色」
3. 机内 3D LUT 变换——CP 只有 12 对 (Cb,Cr) + 增量表，矩阵 + 曲线拟合残差 0.148 已是模型极限
4. 4K120 的卡速门——V60 卡被速率等级挡住，判定代码在 `.text`，当前 260 扇区写窗口不含
5. 像素位移多帧合成 / 动态增强防抖——未完成，保持关闭
