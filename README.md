## FL2 与 FL3 为什么没有

当前版本不提供 A6700 的 FL2／FL3 原生外观功能。相关兼容性研究尚未形成可用版本，不承诺发布时间；请勿将其他机型的配置直接写入 A6700。

> [!IMPORTANT]
> 动手之前，先完整读一遍[操作指南](#操作指南)。软件报错时**先导出诊断包，不要反复重试写入**——重试只会把「也许还能救」变成「救不回来」。

## 能做什么

| 功能                        | 说明                                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **启用／关闭已支持的隐藏功能**      | FTP 相关设置、关机时放下快门帘、电子快门声音（含静音）、灵活曝光。FTP 传输仍有首图后可能卡住的已知问题。                          |
| **创意外观菜单改名**        | 四个外观的显示名换成英文原名或中文简称两套；写入前把整份语言文件存一份底，还原时整份写回、逐字节比对。        |
| **四个外观换色**            | PT／NT／VV／VV2 换成富士 Classic Chrome、Classic Negative，理光正片、负片。只改颜色与色相分布，不动影调曲线。 |
| **「颜色 + 名字」一次写入** | 两段连接、中间自动等复位，约 **2 分钟**一次做完。**中途不能拔线、断电、关相机。**                             |
| **一键还原**                | 可关闭已支持功能、还原颜色或菜单文字；功能状态可备份成 `.a6700backup`。这些备份不是整盘镜像，不保证恢复整机出厂状态。          |
| **驱动准备**                | 随包带驱动组件，可以不联网；绑 WinUSB 一键完成，相机切到认证后的第二种连接时，程序自己把驱动补上。            |
| **离线自检**                | `--offline-self-test` 九项，不接相机也能查环境。                                                              |

**还在做**：电子快门自定义声音（等开发）、CC 的强度再调一档（等实拍看效果）、蓝端的颜色还差一点；FL2／FL3 原生外观（固件里没有这一层，得自己补，见[前面](#fl2-与-fl3-为什么没有)）。

**不做**：整盘固件备份、机内 3D LUT、录像卡速档位、像素位移、动态防抖。机内 LUT 那一层机身里确实有，但拍照这条路没有可用的数据，硬往下造会写坏相机，所以暂停。卡速档位与动态防抖是上游试过没稳住，已撤回。

每次写入前都会先把相机读一遍，遇到不认识的内容就停；程序里没有「强制写入」这个开关。每一项改了什么、验到哪一步、边界在哪，写在 [docs/FEATURES.md](docs/FEATURES.md)。

## 开始前必读

- **电量：**最好在80%以上。写入中途没电和拔线是一个后果。
- **USB 模式：**相机菜单里把 USB 连接设为**海量存储器（MSC）**，别选 MTP 或其他模式。
- **连接：**一根能传数据的 USB-C 线，直插电脑上的 USB 接口（优先黑色 USB 2.0 口；蓝色 USB 3 口如果认不到设备就换黑色口），不经过扩展坞或 Hub。一次只接一台相机。
- **FTP：**关掉（如果有）。首次启用相关功能前本来没有这个菜单，在「相机准备」页勾**没有 FTP 菜单，直接继续**。
- **正常现象：**连接或切换驱动时，相机可能显示**「请检查所连接的设备」**，电脑上的盘符也可能消失。成功与否以软件里的进度和日志为准，**不要因为这句话拔线或重装驱动**。
- **写入时：**<mark>软件显示正在执行时，不要拔线、不要关机、不要关软件</mark>，只有软件明确提示读写结束后，才按提示操作。
- **断电重开：**每次写完都要做下面这五步，少一步设置就可能没落盘。

> [!NOTE]
> **断电重开**贯穿整个流程，每次写入之后都要走一遍。只关机再开机不算。
>
> 1. 拔掉 USB 线。
> 2. 等存取灯停止闪烁。
> 3. 把电源拨到 OFF，等屏幕和存取灯完全熄灭。
> 4. 取下电池，**至少等满 1 分钟**。
> 5. 装回电池，开机。
>
> 开机后先确认能正常拍摄、菜单能进，再考虑下一次写入。新写入的内容要这样才会真正加载。

## 操作指南

按顺序走六步。左边导航就是顺序，右上角写着第几步、共几步，每页底部有「上一步 / 下一步」；前一步没做完，下一步是灰的，并直接告诉你还缺什么。

```text
第 1 步 解压并启动 → 启动检查全绿 → 勾选阅读确认
   │
第 2 步 驱动准备（第一次才需要）──失败──→ 卸载驱动 → 拔插数据线 → 重装／Zadig 手动
   │
第 3 步 相机准备（FTP 关、海量存储、自动关机、只接一台）
   │
第 4 步 只读检查 ──不兼容──→ 停下：看差异明细 → 导出诊断包 → 别重试
   │
第 5 步 启用／关闭功能 → 写入 → 读回核对 → 断电重开 → 机身上核对
   │
第 6 步 备份与恢复
```

### 第 1 步：解压并启动

把 zip 完整解压到一个自建目录（例如 `D:\Powerful6700`），右键点 `Powerful6700.exe`，选**「以管理员身份运行」**。压缩包里那份 [必读.txt](packaging/必读.txt) 讲了解压放哪、如何核对系统安全提示、驱动怎么装、还原怎么走，第一次照着走一遍。

打开后先点 **开始启动检查**。几项都变绿、右下角显示环境就绪，再勾选页面上的阅读确认，底部的**下一步**才会亮。

![操作前须知：七条须知与启动检查](docs/images/notice.png)

七条须知里，前两条是 0.3.8 新加的：写的是机身内部存储、写完必须等满 60 秒；其余是适配范围、当前版本与验证进度、设备与数据风险、保修与官方支持、使用边界。看完再勾。

### 第 2 步：驱动准备（只在第一次需要）

打开左边**驱动准备**：

1. 点**扫描设备**，能认到相机的存储设备就算通。
2. 驱动组件随包带着，不用联网，第一次运行会自动放到数据目录。
3. 点**绑定 WinUSB**。绑好之后资源管理器里的相机盘符会消失，这是正常的。

第一次做只读检查时，相机会自己切到认证后的第二种连接（日志里叫「服务模式」）；程序会发现它、给它补装驱动，不用你手动来。

![驱动准备页：扫描设备与绑定 WinUSB](docs/images/driver.png)

装不上就按[常见问题](#常见问题)里「代码 28」「盘符不见了」两行处理：先卸载再重装，别连着点。

### 第 3 步：相机准备

在相机上确认四件事，界面上每一项都写了菜单路径：

1. FTP 功能关掉。首次启用相关功能前本来没有这个菜单，勾**没有 FTP 菜单，直接继续**。
2. USB 连接模式选海量存储器（MSC），改之前先拔线。
3. 自动关机关掉，电量留够。
4. 最后再接线，只接一台 A6700。

四项都勾上，点**开始只读检查**。

![相机准备页：四项前置条件](docs/images/preparation.png)

### 第 4 步：只读检查

这一步**不写相机**。结果页会告诉你这台机器兼不兼容，以及六项功能现在是开还是关。

![功能管理页：六项功能与当前状态](docs/images/home.png)

报「内容或布局不匹配，已停止」就是被结构守卫拦下了：机身里的内容和程序认识的对不上，程序不会硬着头皮往下写。0.3.8 起结果页会列出每一处差异（偏移、字节、属于哪一类），可以点**复制诊断信息**或**导出诊断包**，先检查并脱敏诊断包，再将必要信息提交到 Issue。**<u>不要换版本反复试</u>。**

### 第 5 步：启用或关闭功能

在**功能管理**勾上要处理的功能，点启用或关闭对应功能的按钮（当前界面文字为**解锁所选功能**／**关闭所选功能**）。写入流程是：先在相机的内存里核对一遍，再写进去，再读回来对一次。

结果页会给出四种结果之一：成功了、本来就是关着的、被拒绝、已经回滚。看到成功之后，[断电重开](#开始前必读)，再到机身上逐项核对。以电子快门声音为例：重开后菜单里应该多出四项，挑非静音的那项，按快门能听到对应声音。

> [!WARNING]
> 中途掉线、软件报错、相机自己黑屏时，**立刻停手，不要重新点一次**：先拔线，再按[断电重开](#开始前必读)的五步做一遍（电池至少取下 1 分钟）。能正常开机就重新做一次只读检查；一直是黑屏、反复重启，或者电脑彻底认不出来，就是需要硬件恢复的情况：按[硬件说明](https://github.com/xyzhangxin/sony-a6700-powerful/blob/main/硬件说明.md)接线救，或者送修，别连着重试。

### 第 6 步：备份与恢复

- **备份当前功能状态**会生成一个 `.a6700backup` 文件，结果页给出路径和校验值。
- **恢复整份备份**是把整份功能状态写回去再读一遍核对，跟你上次勾了哪几项无关。
- 备份只认同机型、同固件，换了机型或固件版本会被拒绝。

写完同样要[断电重开](#开始前必读)。备份文件放在哪，界面下方写着；换电脑前先把它拷走。

## 单独使用各功能

这一页的功能可以单独用。所有写入都是「写入 → 完整读回 → 断电重开」三步，任何一步被打断，按[常见问题](#常见问题)里「中途掉线」那行处理。

### 四个外观

菜单里那四个外观可以换成富士和理光的观感：

| 菜单项         | 换成                      |
| -------------- | ------------------------- |
| PT（第 2 项）  | Classic Chrome            |
| NT（第 3 项）  | Classic Negative          |
| VV（第 4 项）  | 理光正片（Positive Film） |
| VV2（第 5 项） | 理光负片（Negative Film） |

![自定义外观页：四个槽位并排列出「原厂 → 改写为」](docs/images/looks.png)

拿官方直出当过参照，四个外观的逐色相矫正率是 81.7% / 82.7% / 81.1% / 67.0%。这个数字按色相算接近程度，不等于肉眼觉得「八成相似」，实拍还是自己按几下快门最清楚。理光正片和负片目前是低饱和的轻量版。

改法有两种，界面点，或者命令行：

```powershell
python tools/looks_apply.py --confirm yes-write   # 相机先切到海量存储器（MSC）
```

颜色改在相机的运行内存里，当场就能看见；想让它过夜还在，按[断电重开](#开始前必读)走一遍。点**还原本页外观**就回到出厂颜色。

### 菜单文字

菜单上的名字是另一件事，也在这一页，两套叫法随便切：

- 官方原名：Classic Chrome / Classic Neg. / Positive Film / Negative Film
- 中文简称：富士CC / 富士NC / 理光正片 / 理光负片

名字写进去就一直在，不用等关机。写入前程序会把整份语言文件存一份底（约 142 KB），还原时整份写回去并对一遍哈希；本地没有底的话只能改回出厂短名，界面会老实说这一档不是逐字节还原。

### 一次写入（颜色 + 名字）

想一次把颜色和名字都弄好，用「一次写入：颜色 + 名字」那张卡片：程序先写颜色，断开，等相机缓一分钟，再连上写名字，全程两分钟上下，**<mark>中间不用你拔线</mark>**。分两次连不是磨蹭——一次连接里干太多事相机会掉线，文件会停在一半。

- 前半段失败就整段停下，名字一个字都不动。
- 后半段失败会保留已经写好的颜色，并告诉你可以单独回滚。

> [!WARNING]
> 这条路动的是机身固件侧的分区（菜单文字包所在的那一块），不是 SD 卡。两段连接之间**不能拔线、断电、关相机**：第二段正在写菜单文字，中途断掉会停在半截，可能黑屏、反复重启。按钮第一次点要勾一句确认（提醒的就是这件事），写完自动重新上锁；「一次还原」不受限制。

**做不到的**：这台相机没有能改影调的那一层，所以只能改颜色倾向，出不来富士那种 S 形曲线；`.cube` 和 `.dcp` 文件不能直接导进去；整盘固件备份也没有，上游没做，这里不发明。细节在 [docs/LOOKS.md](docs/LOOKS.md) 和 [docs/ROADMAP.md](docs/ROADMAP.md)。

## 常见问题

| 现象                                        | 处理                                                                                                                                                                                                                                                     |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 相机显示「请检查所连接的设备」              | 正常现象。以软件里的进度和日志为准，不要因此拔线或重装驱动。                                                                                                                                                                                             |
| 卡在「正在等待相机进入服务模式」            | 老版本会卡住并把相机留在那个连接上。现在会自己发现那台设备、补装驱动，失败时也会试着把相机送回来；实在不行拔插一次数据线。                                                                                                                               |
| 设备管理器显示「无法安装此设备（代码 28）」 | 认证后那台设备还没驱动。点**驱动准备 → 扫描设备 → 绑定 WinUSB**，或者重试一次只读检查让程序自己补。                                                                                                                                                      |
| 绑完驱动，相机盘符不见了                    | 正常。绑好之后相机不再以移动盘出现，只对程序可见。想恢复，在设备管理器里把它卸掉再拔插一次。                                                                                                                                                             |
| 只读检查报「内容或布局不匹配，已停止」      | 被结构守卫拦下，没有写入任何东西。看结果页的**差异明细**，点**复制诊断信息**或**导出诊断包**，脱敏后提交到 Issue。**不要换版本反复试。**                                                                                                                         |
| 结果页显示「结果未知」或「需要核对」        | **不要重试写入。**先导出诊断包，再对照机身现象：能开机就断电重开、重新只读检查；开不了机按下一行处理。                                                                                                                                                   |
| 写入中途掉线、软件报错、相机黑屏            | 立刻停手：拔线 → 取电池等满 1 分钟 → 只装电池开机。能开机就断电重开后重新只读检查；连不上、一直黑屏或反复重启，就是要硬件恢复（接线见[硬件说明](https://github.com/xyzhangxin/sony-a6700-powerful/blob/main/硬件说明.md)），或者送修。**不要连续重试。** |
| 写坏了还能自己还原吗                        | 还原也是连上相机再写回去。只要相机还能开机、插上数据线还能被认成海量存储器（MSC），软件这边就还有退路；连这个都出不来，只剩硬件恢复。                                                                                                                    |
| 写完了但设置没生效、颜色回退                | 多半是没做断电重开。按[开始前必读](#开始前必读)的五步再来一次，别先怀疑写入失败。                                                                                                                                                                        |
| 「恢复整份备份」是灰的                      | 得先做一次只读检查，而且要有一个同机型、同固件的备份文件。                                                                                                                                                                                               |
| 为什么不做整盘固件备份                      | 上游没有这个能力，这里也没自己造。现在存的是功能状态快照，不是整盘镜像，救不了变砖。                                                                                                                                                                     |
| FL2／FL3 什么时候有                         | 这两个位子在 A7C2 那代固件里自带，只是没放开；A6700 固件里没有，得自己补，目前还在试，不承诺时间。见 [FL2 与 FL3 为什么没有](#fl2-与-fl3-为什么没有)。                                                                                                   |
| 要装 Python 吗                              | 不用，绿色版自带运行时。只有从源码跑才需要 Python 3.10 以上。                                                                                                                                                                                            |

> [!NOTE]
> 诊断包里有设备信息、本机路径和最近的日志，公开贴出来之前先自己看一遍。请检查包内全部文件，移除不希望公开的用户名、路径、设备标识及其他私人信息；不要上传原始备份或设备转储。

## 命令行与开发

图形界面已经覆盖日常使用。下面这些入口给开发和排错用：

| 入口                                                  | 用途                                                       |
| ----------------------------------------------------- | ---------------------------------------------------------- |
| `Powerful6700.exe`                                    | 打开界面。不接相机也能开，打开本身不连接、不写入。         |
| `Powerful6700.exe --offline-self-test`                | 九项离线自检；加 `--json selftest.json` 输出机器可读结果。 |
| `Powerful6700.exe --diagnose`                         | 打印环境诊断 JSON。                                        |
| `Powerful6700.exe --inspect-once --json inspect.json` | 接相机只读检查一次，不写相机。                             |
| `Powerful6700.exe --render-pages shots`               | 把七个页面渲染成截图，验证冻结包里的界面。                 |

源码开发：

```powershell
.\.venv\Scripts\python.exe -m pip install --no-index --find-links wheelhouse -r requirements.txt
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe -m PyInstaller packaging\Powerful6700.spec --noconfirm
```
