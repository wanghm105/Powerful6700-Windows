Powerful6700 · Windows 使用前必读
适配范围：Sony A6700（ILCE-6700），相机固件 2.00。

本项目是免费开源的非官方工具，与 Sony 或相关配色品牌无隶属、授权或背书关系。作者没有授权任何人以作者名义收费代刷、远程安装或承诺保修。项目按现状提供，不保证操作成功；本说明不排除法律禁止免除的责任。

一、用途与限制
可配置已支持的隐藏功能、四个创意外观的近似配色和菜单名称。当前不提供 A6700 的 FL2／FL3 原生外观功能。FTP 仍有首图后可能卡住的已知问题。
部分操作会写入机身内部存储及固件侧资源分区；本工具不提供整盘固件备份。功能快照和局部备份不能代替整机恢复镜像。

二、操作风险
写入中断或内容不兼容可能造成黑屏、反复重启、无法开机、设置或数据丢失，也可能影响官方更新、保修或维修。
项目已有设备写入异常的故障记录。读回一致、历史测试或他人成功反馈均不保证本次操作安全；软件还原和硬件恢复都不保证成功。
只操作本人合法持有或已获机主明确授权的设备。无法承担设备损坏或维修风险时，请勿使用。

三、下载与启动
从本项目 GitHub Releases 下载，核对下载页提供的 SHA-256。校验值一致仅说明文件与所列版本一致，不是安全认证。
将压缩包完整解压到自建目录，保留 EXE、_internal 及随附文件。首次驱动安装需要管理员权限。
遇到 SmartScreen 或安全软件提示时，先核对来源、校验值和具体检测信息；无法确认时停止运行。不要仅凭“未签名”就认定安全，也不要关闭安全软件来继续安装。
离线环境检查：Powerful6700.exe --offline-self-test。自检通过不代表真机写入已验证。

四、操作顺序
完整阅读仓库 README 的操作指南与界面风险提示，依次完成启动检查、驱动准备、相机准备和只读检查。
只连接一台受支持设备，使用可靠的数据线和稳定供电；检查不通过时停止，不要绕过兼容性检查或换版本反复尝试。
写入前保存备份，核对本次操作对象与影响。进行中不要拔线、断电或关闭程序；仅在软件明确提示读写结束后，按结果页和 README 的顺序操作。
完成后按说明重启设备并核对功能。恢复操作仍需要设备能够建立受支持的连接。
界面中的“解锁所选功能”表示启用所选的已支持功能；按钮名称以当前版本界面为准。

五、失败与反馈
出现写入失败或“结果未知”时停止重复写入，保存诊断信息，按结果页及 README 处理。设备黑屏、反复重启或不能连接时，可能需要硬件恢复或专业维修；不要连续重试。
诊断包可能含设备信息、本机路径和日志。公开上传前逐项检查并脱敏；不要上传个人凭据、原始设备备份、校准数据或完整转储。
