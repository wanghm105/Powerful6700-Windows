Powerful6700 · Windows —— 必读
版本 0.3.0　只适配 Sony A6700（ILCE-6700）+ 相机固件 2.00
非 Sony 官方工具，GPL-3.0 开源，按现状提供，不保证操作成功。

------------------------------------------------------------
一、这个工具做什么
------------------------------------------------------------
1）解锁 / 关闭四项机身功能：原生 FTP 菜单与相关设置、关机快门罩与静音联动、
   灵活曝光、电子快门声音。写入前先做只读体检，写完相机内校验 + 电脑独立回读，
   并且可以整份备份、整份还原。
2）把菜单里 PT / NT / VV / VV2 四个外观的颜色记录，换成富士 Classic Chrome、
   Classic Negative 与理光正片 / 负片的配色（只改颜色浓度与色相分布，不改影调曲线）。

不支持：A7C2 与其它机身、A6700 的其它固件版本；本工具不刷固件、不提供整盘固件备份。

------------------------------------------------------------
二、第一次打开：解压与启动
------------------------------------------------------------
1. 把压缩包整个解压到你自建的文件夹，例如 D:\Powerful6700。
   ● 不要只把 Powerful6700.exe 拷出来：它必须和同级的 _internal 文件夹放在一起。
   ● 不要放在 C:\Program Files 这类只读位置，否则备份和运行记录写不进去。
2. 双击 Powerful6700.exe。不用装 Python，也不用装其它运行库。
3. 如果弹出蓝色的「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
   这表示程序没有做代码签名，不是病毒。少数杀毒软件会误报这类打包程序，需要加白名单。
4. 运行后会在程序目录下自动生成 .data 文件夹：
   .data\backups = 功能状态备份，.data\runs = 每次操作的记录，
   .data\driver = 驱动组件，.data\state = 程序状态。
   换电脑时把这个文件夹一起带走，备份就跟着走。

------------------------------------------------------------
三、第 1 步：操作前须知
------------------------------------------------------------
1. 把「适用范围与风险」五条读一遍（机型、验证进度、设备与数据风险、保修、许可）。
2. 勾选卡片右上角的「我已阅读，并了解适用范围与真实设备操作风险」。
3. 点「开始启动检查」：检查 Python 环境、平台、PyUSB、libusb 与固定范围载荷完整性。
4. 全部通过（绿勾）后，右下角出现「下一步：驱动准备」。
   若某项显示跳过，按页面提示处理；驱动组件那一项可以在下一页下载。

------------------------------------------------------------
四、第 2 步：驱动准备（每台电脑只需做一次，需要管理员）
------------------------------------------------------------
1. 先在相机里把 USB 连接模式设为「USB 海量存储 / MSC」，只连这一台相机，不要经过外接集线器。
2. 点「下载驱动组件」（联网，几 MB，存到 .data\driver）。
3. 点「扫描设备」，列表里应出现索尼相机接口（常见 PID 0x0E76，也可能是 0x047D / 0x0336）。
4. 点「绑定 WinUSB」，会弹管理员授权（UAC），选「是」。
5. 列表里显示「服务：winusb」就完成了，之后不用再重复绑定。

注意：安装驱动只针对索尼相机的这三个 PID，不会动其它 USB 设备。
如果不给管理员权限，绑定一定失败，后面的读写也做不了。

------------------------------------------------------------
五、第 3 步：相机准备
------------------------------------------------------------
页面上四项按顺序做（每条都写了相机里的菜单路径）：
  1) FTP 功能设为关（只有当机内有这个菜单时才需要处理）
  2) USB 连接模式设为「海量存储（MSC）」，不要选 MTP / 电脑遥控 / USB 流式传输
  3) 关闭自动关机开始时间，确认电量充足（写入中途断电很危险）
  4) 最后再插 USB 数据线，只连这一台相机，保持开机
四项都勾选后，点「全部确认」→「开始只读检查」。

只读检查会读取固定范围的 260 个扇区（133,120 字节）逐字节比对清单，不修改任何东西。
通过后自动进入下一步；不通过就按提示处理，不要强行继续。

提示：MSC 模式下相机不能拍照。要拍样张先把相机切回拍照模式，需要写的时候再切回 MSC。

------------------------------------------------------------
六、第 4 步：功能管理（解锁 / 关闭 / 备份 / 恢复）
------------------------------------------------------------
1. 上方会显示只读检查结论：兼容性、读取扇区、读取字节、功能项数量。
2. 建议先点「备份当前功能状态」存一份带 SHA-256 的备份（在 .data\backups）。
3. 勾选要改的功能（也可以「全选」），点「解锁所选功能」；要关掉就点「关闭所选功能」。
   未开放的两项（位移多帧合成、动态增强防抖）在清单里标记为未开放，不要选。
4. 写入过程会显示在「进度」卡片里，中途不要关窗口、不要拔线、不要动相机。
5. 完成后到「操作结果」页看结论（completed / no-op / 已回滚 等），并按「机身验收」提示：
   正常关机 → 开机 → 按页面上列出的菜单路径逐项确认功能是否真的生效。
6. 想还原：「关闭所选功能」可以逐项关掉；「恢复整份备份」直接把整份功能状态写回（与勾选无关）。

------------------------------------------------------------
七、第 5 步：自定义外观（可选）
------------------------------------------------------------
1. 相机切到「USB 海量存储（MSC）」，只连这一台，全程不断线。
2. 点「检测当前状态」，看四条记录现在是「出厂外观」还是「已写入配方」。
3. 点「写入配方」：写 CP 色度单元，四条颜色记录，写完整单元回读校验。
4. 写完必须正常关机一次，再开机。相机会在关机时把当前状态写进 /setting/BACKUP.BIN，
   少了这一步，重启后可能看不到效果。
5. 想恢复原厂配色：点「还原本页外观」，同样关机一次。

这一步只写相机的颜色记录，不碰任何固件分区，不存在刷坏固件的风险。
菜单里显示的外文名字（Classic Chrome 等）不是这一步改的，默认也不改。

拟合到什么程度：CC / NC 逐色相误差约 0.18 / 0.17，PF / NF 只做到低饱和近似（0.19 / 0.33）。
三条硬边界：蓝端压不下来；本机型只有 12 组 (Cb,Cr) 加一个宽把手，做不出 NC 的窄品红缺口；
没有富士的 S 形影调曲线。请把它当「颜色层面的近似」，不是原厂原味。

------------------------------------------------------------
八、还原到出厂
------------------------------------------------------------
● 四项功能：功能管理 →「关闭所选功能」，或「恢复整份备份」。
● 四个外观：自定义外观 →「还原本页外观」→ 正常关机一次。
● 严格来说改不回去的只有两处：写 /usr 时必然更新的 inode 时间戳（12 字节，不影响功能）；
  以及本工具没有整盘固件备份能力（但它从不写固件本体）。

------------------------------------------------------------
九、常见问题
------------------------------------------------------------
1. 提示 no Sony MSC device found：相机没在「USB 海量存储」模式，或者用的是充电线。
   切模式、换数据线，再点「重新连接」。
2. 提示需要管理员：绑定 WinUSB 必须允许 UAC 授权。
3. 扫描不到相机接口：先「下载驱动组件」再「扫描设备」；相机要开机、别让它休眠。
4. 相机连不上或卡住：关相机再开，重新选一次 MSC 模式；重新连接时程序会尝试自动恢复。
5. 一直显示「操作进行中」：别关窗口、别拔线，等「进度」走完。
6. 备份和记录在哪：.data\backups、.data\runs。反馈问题时把 .data\runs 里的文件一起带上。
7. 写入中途拔线或断电：重新连接再写一次即可。外观写入会被断电丢弃，回到上一次落盘的状态。
