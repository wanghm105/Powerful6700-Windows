------------------------------------------------------------
手把手安装教程
------------------------------------------------------------
按下面顺序做，别跳步；哪一步不确定就先停下。
解压 → 启动 → 七条须知 → 驱动 → 相机准备 → 只读检查 → 功能 / 颜色 / 改名 → 关机验收。

------------------------------------------------------------
一、能做什么
------------------------------------------------------------
● 四项隐藏功能：原生 FTP、关机快门帘与静音、灵活曝光、电子快门声音（四档含静音；自定义声音在开发）。
● 四个外观（PT / NT / VV / VV2）换富士 Classic Chrome、Classic Negative 与理光正片 / 负片的配色。
● 菜单名换英文原名或中文简称；也可「颜色 + 名字」一次写完。
只支持 A6700 + 固件 2.00；不刷固件、不做整盘备份。FL2／FL3 在 A7C2 固件里自带、只是没放开，
A6700 没有这一层，还在试，不承诺时间。

------------------------------------------------------------
二、解压与启动
------------------------------------------------------------
1. 整个包解压到自建目录（如 D:\Powerful6700）；exe 与 _internal 同级，别只拷 exe、别放 Program Files。
2. 右键 exe →「以管理员身份运行」；SmartScreen 点「更多信息 → 仍要运行」（没签名，不是病毒）。
3. 程序目录会生成 .data（backups / runs / driver / state），换电脑一起带走。
4. 验环境：PowerShell 执行 .\Powerful6700.exe --offline-self-test，九项 OK 即可。

------------------------------------------------------------
三、第 1 步：操作前须知
------------------------------------------------------------
1. 读完七条，前两条是 0.3.8 新加的：改的是机身里的东西、不是 SD 卡；写完要拔线、关机、等满 60 秒再开机。
   其余五条：适配范围、当前版本与验证进度、设备与数据风险、保修与官方支持、使用边界。
2. 勾选「我已阅读…」→「开始启动检查」，全绿后进入下一步。

------------------------------------------------------------
四、第 2 步：驱动准备（每台电脑一次，需管理员）
------------------------------------------------------------
1. 相机 USB 设 MSC，只连这一台，不经集线器。
2. 驱动组件随包（wdi-simple），不用联网；仅 _internal\third_party\libwdi 被杀软删掉时点「下载驱动组件」。
3. 「扫描设备」→ 出现 Sony 接口（0x0E76 / 0x047D / 0x0336）→「绑定 WinUSB」→ UAC 选「是」。
4. 显示「服务：winusb」即完成，只针对这三个 PID；不给管理员权限一定失败。

------------------------------------------------------------
五、第 3 步：相机准备
------------------------------------------------------------
四项依次做（页面写了菜单路径）：1) FTP 关（没有就勾「没有 FTP 菜单，直接继续」）；
2) USB 设 MSC（别选 MTP / 电脑遥控）；3) 关自动关机、电量 80% 以上；4) 最后插线、只连一台、保持开机。
四项勾完 →「全部确认」→「开始只读检查」。MSC 下不能拍照，拍样张先切回拍照模式。

------------------------------------------------------------
六、第 4 步：只读检查
------------------------------------------------------------
● 读 260 个扇区 / 133,120 字节，逐字节比对，不改东西；不通过就停。
● 被结构守卫拦下时会列出每处差异（偏移、字节、类别），可「复制诊断信息」/「导出诊断包」贴 Issue。别换版本反复试。

------------------------------------------------------------
七、第 5 步：功能管理
------------------------------------------------------------
1. 先「备份当前功能状态」（.data\backups，带 SHA-256）。
2. 勾功能 →「解锁所选功能」/「关闭所选功能」；未开放两项（位移多帧合成、动态增强防抖）别选。
3. 确认框写清：写哪里（机身，不是 SD 卡）/ 多少字节 / 怎么回滚；默认「先不写」。
4. 进度中别关窗、别拔线；完成后按结果页（成功 / 本来关着 / 被拒绝 / 已回滚）和「机身验收」核对：
   正常关机 → 开机 → 按菜单路径逐项看。
5. 还原：「关闭所选功能」逐项关，或「恢复整份备份」。

------------------------------------------------------------
八、第 6 步：自定义外观（颜色，可选）
------------------------------------------------------------
1. MSC、只连一台、不断线 →「检测当前状态」→「写入配方」（写 CP 色度单元四条记录，整单元回读校验；同样弹确认框）。
2. 写完必须正常关机一次再开机：关机时才写 /setting/BACKUP.BIN，少这步可能看不到效果；还原同样关机一次。
3. 只改颜色记录，不碰固件分区；中途断电按「十二」。
拟合：CC / NC 误差约 0.18 / 0.17，PF / NF 低饱和近似 0.19 / 0.33；蓝端压不下来、做不出 NC 窄品红缺口、没有 S 形曲线。
请当颜色近似，不是原厂原味。

------------------------------------------------------------
九、第 7 步：菜单改名（可选）
------------------------------------------------------------
1. 选「官方原名」或「中文简称」（存数据目录）。
2. 「写入名字」改固件分区里的简体中文文字包 /usr/share/app/string_simplifiedchinese_f.uxc
   （整份约 142 KB，分块写、逐块读回核对）；写前自动存底稿。
3. 立即生效，不用关机；写入中不能拔线、断电、关相机。

------------------------------------------------------------
十、一次写入（颜色 + 名字）
------------------------------------------------------------
1. 两段连接约 2 分钟，中间不用你拔线；两段之间不能拔线、断电、关相机（第二段在写菜单文字）。
2. 按钮默认锁，勾一句确认才解锁；写完自动上锁，「一次还原」不受限。
3. 前半段失败→名字不动；后半段失败→保留颜色并提示可单独回滚。

------------------------------------------------------------
十一、还原到出厂
------------------------------------------------------------
● 功能：关闭所选功能 / 恢复整份备份。● 外观：还原本页外观 + 关机一次。
● 名字：把名字改回去（本地底稿整份写回）。
● 改不回去的只有两处：文字包的文件系统记录（时间戳等，不影响功能）；本工具没有整盘固件备份（也从不写固件本体）。
● 还原也要先连得上：能开机、能被认成 MSC 才有退路；出不来只剩硬件恢复。

------------------------------------------------------------
十二、写入失败、相机黑屏
------------------------------------------------------------
立刻停手：1) 拔线，别再插；2) 取电池，等满 1 分钟以上再装回；3) 只装电池开机——能进菜单就救回来了，
一直黑屏或反复重启只剩硬件恢复。
不要连续重试、不要反复插拔数据线——那会让相机更久连不上电脑，连 MSC 都不出现。

● 能开机：断电重开（拔线 → 关机 → 等满 60 秒 → 只装电池开机），再重新只读检查。
● 开不了机：按上游硬件说明接线救（RP2040 Pico + USB-C 24P 测试板，从 USB-C 口冷启动注入，不用拆机）：
  https://github.com/xyzhangxin/sony-a6700-powerful/blob/main/硬件说明.md
  国内可能打不开：让朋友存成 PDF 发你，别信「寄过来帮你修」。

------------------------------------------------------------
十三、常见问题
------------------------------------------------------------
1. no Sony MSC device found：模式不对或充电线；切 MSC、换线，再「重新连接」。
2. 需要管理员：UAC 必须允许。3. 扫描不到：确认 libwdi\wdi-simple.exe 还在，相机开机不休眠。
4. 连不上 / 卡住：关相机再开、重选 MSC。5. 「操作进行中」：别关窗别拔线，等进度。
6. 「结果未知」：别重试，先导出诊断包；能开机就断电重开 + 只读检查，否则按「十二」。
7. 「请检查所连接的设备」：正常，以进度和日志为准。8. 备份 / 记录：.data\backups、.data\runs（反馈带上 runs）。
9. 中途拔线 / 断电：别连写第二次，按「十二」。10. 换机型 / 固件：会被拒绝，别绕过。
11. 电子快门自定义声音：还在开发，没有时间表。
